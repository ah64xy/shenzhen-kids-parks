# 深圳遛娃好去处

适合 2 岁及以下低龄宝宝的公园与室内亲子场所推荐，含简介、地址、地铁出行。

## 在线地址
- 网站：https://ah64xy.github.io/shenzhen-kids-parks/
- 管理后台：https://ah64xy.github.io/shenzhen-kids-parks/admin/

## 技术说明
- 静态页面 + parks.json 数据文件，由 GitHub Pages 免费托管
- 后台通过 GitHub API 直接编辑 parks.json / 上传图片，保存后自动上线
- 当前收录 33 个场所，覆盖福田、罗湖、南山、龙岗、宝安、光明等区

## 维护
- 打开管理后台，粘贴 GitHub 个人访问令牌（需 repo 权限）即可编辑
- 令牌仅保存在浏览器 localStorage，不会上传到服务器
